Instructions for FM / PM Side-by-Side Comparison

  • Note: This page generates one message signal and modulates it with both FM and PM, so you can directly compare how each responds to the same input.
  • Step 1: Use the sliders to set message frequency, carrier frequency, Kf (FM frequency sensitivity), and Kp (PM phase sensitivity).
  • Step 2: Click "Generate Comparison" to plot the FM and PM signals side by side, both from the same message and carrier.
  • Tip: Watch how a higher Kf makes the FM signal's instantaneous frequency swing more, while a higher Kp makes the PM signal's phase jumps more abrupt at each message zero-crossing.
